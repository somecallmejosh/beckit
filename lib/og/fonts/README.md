Static TTF instances of the app's own fonts (OFL), for drawing social cards with libvips, which cannot read WOFF2.
Made from app/assets/fonts with fontTools (varLib.instancer): Lora at weight 500, Inter at 400 and 500 (opsz 32),
renamed to "OG Lora", "OG Inter" and "OG Inter Medium" so Pango can tell them apart.
